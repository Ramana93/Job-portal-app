# 💼 Job Portal Web Application

## 📌 Project Overview
The Job Portal Web Application is a full-stack web application developed using Django.  
It allows users to register, login, post jobs, edit jobs, delete jobs, and apply for jobs.

This project demonstrates:
- Backend development using Django
- Database management using SQLite
- User authentication system
- CRUD operations
- Template rendering
- Form handling

---

## 🚀 Features

- User Registration & Login
- Secure Authentication System
- Create Job Posts
- Edit Job Posts
- Delete Job Posts
- Apply for Jobs
- View Job Listings
- Admin Panel Access
- Responsive UI Design

## ⚙️ Installation & Setup Guide

### 1️⃣ Clone the Repository

git clone https://github.com/Ramana93/Job-portal-app.git

### 2️⃣ Navigate to Project Folder

cd Job-portal-app

### 3️⃣ Create Virtual Environment

python -m venv myenv

### 4️⃣ Activate Virtual Environment

Windows:
myenv\Scripts\activate

### 5️⃣ Install Dependencies

pip install -r requirements.txt

### 6️⃣ Apply Migrations

python manage.py migrate

### 7️⃣ Run Development Server

python manage.py runserver

Now open:
http://127.0.0.1:8000/
