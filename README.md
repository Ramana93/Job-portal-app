# Job Portal Web Application

## 📌 Project Overview
The Job Portal Web Application is a full-stack web application developed using Django.  
It allows users to register, login, post jobs, and apply for jobs.  
This project demonstrates backend development, database management, authentication, and CRUD operations.

---

## 🚀 Features

- User Registration & Login
- Authentication System
- Post Job Listings
- Edit & Delete Job Posts
- Apply for Jobs
- View Available Jobs
- Admin Panel Access
- Responsive UI

---

## 🛠️ Technologies Used

- Python
- Django
- SQLite
- HTML
- CSS
- Bootstrap (if used)

---

## 🗄️ Database

- SQLite (default Django database)
- Django ORM for database operations
